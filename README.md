# React Practice — Describing the UI

A small practice project built while working through react.dev's
"Describing the UI" module. Fan characters used for practice data
only — this is a learning exercise, not an original app.

## Concepts practiced
- Components, named vs. default exports
- JSX + curly braces (including double-curly `style={{...}}` objects)
- Props, default parameter values, and `children`
- Conditional rendering
- Rendering lists with `.map()` and `key`
- Component purity (see separate purity demo, not part of main app)

## Tech
React + Vite

## Notes
Images are stored locally under `public/images/` rather than
hotlinked, for reliability.
